# Library System / نظام إدارة المكتبة

```
npm start
```

## Skills
Installed from https://skill-ps.apps.taqat.academy/ :
```
npx skills add anthropics/skills --skill frontend-design --agent claude-code
```
Add more (e.g. `obra/superpowers`, `mattpocock/skills`) the same way.
